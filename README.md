# 🎓 Student Management System

A command-line Student Management System built using C++.

This project was built to practice C++ fundamentals, data structures, file handling, and designing a menu-driven application.

The application stores student data in a CSV file, allowing the data to remain available even after the program is closed.

## 🚀 Features

* Add a student
* Display all students
* Search for a student
* Delete a student
* Persistent data storage using a CSV file
* Menu-driven command-line interface

## 🛠️ Tech Stack

* C++
* CSV File Handling

## ▶️ How to Run

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project folder:

```bash
cd <project-folder>
```

Compile the program:

```bash
g++ main.cpp -o student_management
```

Run the application:

```bash
./student_management
```
